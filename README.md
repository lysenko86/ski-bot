# Ski Bot

Telegram бот на Node.js + TypeScript + Telegraf.

## Технології

- Node.js
- TypeScript
- Telegraf
- dotenv
- tsx

## Встановлення

```bash
npm install
```

Бот обробляє команди з меню. На звичайний текст він відповідає підказкою скористатися меню; вільний чат вимкнений.

## Автоматичні сповіщення

Вкажи Telegram chat ID у `ALERT_CHAT_ID` у файлі `.env`. Для сповіщень у групі додай туди бота та задай ID групи. Без `ALERT_CHAT_ID` автоматичний моніторинг не запускається.

Бот перевіряє поточні умови для кожної локації одразу після запуску, а потім кожні 5 годин; між запитами по локаціях витримується 1 хвилина. Сповіщення надсилається, коли температура не вища за −4 °C, опадів немає або йде лише сніг, а сніговий покрив становить щонайменше 7 см.

## Запити на автоматичні сповіщення

Команда `/request` надсилає адміністратору ім’я користувача, його Telegram ID та ID чату, з якого подано запит. Для цього вкажи приватний chat ID адміністратора в `REQUESTS_CHAT_ID` у файлі `.env`. Адміністратор має спершу відкрити приватний чат із ботом і надіслати йому повідомлення. Щоб дізнатися свій chat ID, тимчасово ввімкни команду `/chatid` у `src/bot.ts`, надішли її боту приватно та скопіюй отриманий ID. Після цього вимкни команду. Запити лише повідомляють адміністратора; вони не підписують чати на сповіщення автоматично.

## Аналітика

Команда `/analytics` показує кількість викликів кожної команди за сьогодні, останні 7 днів і останні 30 днів. Вона доступна лише в приватному чаті, ID якого вказаний у `REQUESTS_CHAT_ID`. Аналітика зберігає тільки агреговані лічильники команд за датою, без Telegram ID. Дані записуються у `.data/analytics.json`; для збереження після перезапуску чи redeploy хостинг має підтримувати постійний диск для цієї папки.
