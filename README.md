# Ski Bot

Telegram бот на Node.js + TypeScript + Telegraf.

## Технології

- Node.js
- TypeScript
- Telegraf
- dotenv
- tsx

## Встановлення

```bash
npm install
```

## Автоматичні сповіщення

Вкажи Telegram chat ID у `ALERT_CHAT_ID` у файлі `.env`. Для сповіщень у групі додай туди бота та задай ID групи. Без `ALERT_CHAT_ID` автоматичний моніторинг не запускається.

Бот перевіряє поточні умови для кожної локації одразу після запуску, а потім кожні 5 годин; між запитами по локаціях витримується 1 хвилина. Сповіщення надсилається, коли температура не вища за −3 °C, опадів немає або йде лише сніг, а сніговий покрив становить щонайменше 5 см.
