# Ski Bot

Telegram бот на Node.js + TypeScript + Telegraf.

## Технології

- Node.js
- TypeScript
- Telegraf
- dotenv
- tsx
- [Supabase](https://supabase.com/) — база даних для аналітики
- [Railway](https://railway.com/) — деплой бота

## Встановлення

```bash
npm install
```

Бот обробляє команди з меню. На звичайний текст він відповідає підказкою скористатися меню; вільний чат вимкнений.

## Автоматичні сповіщення

Вкажи Telegram chat ID у `ALERT_CHAT_ID` у файлі `.env`. Для сповіщень у групі додай туди бота та задай ID групи. Без `ALERT_CHAT_ID` автоматичний моніторинг не запускається.

Бот перевіряє поточну погоду та прогнози на завтра, післязавтра і через 4 дні (о 11:00) одразу після запуску, а потім кожні 5 годин; між запитами по локаціях витримується 1 хвилина. Якщо для періоду температура не вища за −4 °C, опадів немає або йде лише сніг, а сніговий покрив становить щонайменше 7 см, бот надсилає окреме стандартне повідомлення лише з даними цього періоду.

## Запити на автоматичні сповіщення

Команда `/request` надсилає адміністратору ім’я користувача, його Telegram ID та ID чату, з якого подано запит. Для цього вкажи приватний chat ID адміністратора в `REQUESTS_CHAT_ID` у файлі `.env`. Адміністратор має спершу відкрити приватний чат із ботом і надіслати йому повідомлення. Щоб дізнатися свій chat ID, тимчасово ввімкни команду `/chatid` у `src/bot.ts`, надішли її боту приватно та скопіюй отриманий ID. Після цього вимкни команду. Запити лише повідомляють адміністратора; вони не підписують чати на сповіщення автоматично.

## Аналітика

Команда `/analytics` показує кількість викликів кожної команди за сьогодні, останні 7 днів і останні 30 днів. Вона доступна лише в приватному чаті, ID якого вказаний у `REQUESTS_CHAT_ID`. Аналітика зберігає в Supabase лише агреговані лічильники команд за датою, без Telegram ID. Для підключення задай `SUPABASE_URL` і `SUPABASE_SECRET_KEY` у змінних середовища; секретний ключ має бути доступний лише серверу бота.
